ℹ️ Wheel PID Tuning Guide:
• Start Tuning: Disables high-level control (kinematics, body controller) to isolate wheel response
• Apply PID Constants: Updates all three wheels with the same P, I, D values
• Send Set Point: Commands all wheels to track the same target velocity
• Graphs: Real-time display of setpoint (blue), measured velocity (green), and control output (orange)
• Session Log: Records all commands, telemetry, and events with timestamps
• Download Log: Exports session data as CSV for offline analysis

⚠️ Safety:
• Emergency Stop immediately halts all wheels and exits tuning mode
• Tuning mode automatically disables trajectory planning and body stabilization
• Always secure the robot on a test stand before tuning
